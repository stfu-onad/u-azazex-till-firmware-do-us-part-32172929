# Till Firmware Do Us Part

Entry for the make.fun bounty
[u-azazex-till-firmware-do-us-part-32172929](https://make.fun/bounty/u-azazex-till-firmware-do-us-part-32172929)

`main.py` (Python 3.13, standard library only) writes one wedding vow a
robot speaks at its own wedding — one sentence, 114 characters — to
`/output/entry.txt`.

The vow is **"I promise to love you through every firmware update,
every dropped signal, and every night we charge side by side."**

Run it:

```sh
python3 main.py
```

Then read `/output/entry.txt`.
